# Team 4 - Industrial Theme

Unity project for Team 4's industrial-themed game.

## Getting started

1. Install Unity **6000.3.8f1** in Unity Hub.
2. In Unity Hub, choose **Add** and select this repository's root folder.
3. Open the project and let Unity import the assets and generate its local project files.
4. Create scenes under `Assets/Scenes` and commit source assets and their `.meta` files.

The repository already has the Git remote configured:
`https://github.com/Oral012/Team4_Theme2.git`

## Asset layout

- `Assets/Scenes` - game scenes
- `Assets/Scripts` - gameplay and UI code, grouped by responsibility
- `Assets/Structures` - industrial structures and their models, materials, prefabs, and textures
- `Assets/Art` - shared environment art and source art assets
- `Assets/Prefabs` - reusable environment, interaction, and UI objects
- `Assets/Audio` - music and sound effects
- `Assets/UI` - shared fonts and sprites
- `Assets/Settings` - project-specific settings assets created or configured in Unity

Unity-generated folders such as `Library` are intentionally excluded from Git.
